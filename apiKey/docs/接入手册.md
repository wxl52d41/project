# API Key 接入手册

---

## 一、接入准备

引入依赖即自动生效（无需任何注解），需配置 Redis 连接：

```xml
<dependency>
    <groupId>com.wxl52d41</groupId>
    <artifactId>api-key-spring-boot-starter</artifactId>
    <version>1.0.0-SNAPSHOT</version>
</dependency>
```

```yaml
spring:
  redis:
    host: 127.0.0.1
    port: 6379
    password:
    database: 0

api:
  key:
    enabled: true          # 引入即启用，false 可整体关闭
    prefix: AK-            # Key 前缀
    timeout: 2592000       # 默认有效期（秒），30 天；-1=永久
    is-record-index: true  # 按用户反查 Key 列表（建议开启）
```

数据存于 Redis：`api-key:model:{apiKey}`（凭证）、`api-key:index:{loginId}`（用户索引），多实例天然共享。

## 二、凭证管理

```java
@Resource
private ApiKeyTemplate apiKeyTemplate;

// 创建（自动生成 AK- 前缀 + 36 位安全随机串，默认 30 天有效）
ApiKeyModel ak = apiKeyTemplate.createApiKeyModel(10001)   // loginId
        .setTitle("头像插件")                                // 用途命名
        .setIntro("每日自动更新头像")                         // 描述
        .addScope("userinfo", "avatar")                     // 授权范围
        .addExtra("origin", "plugin-a");                    // 扩展数据
apiKeyTemplate.saveApiKey(ak);

// 查询
ApiKeyModel model = apiKeyTemplate.getApiKey("AK-xxx");      // null=无效
List<ApiKeyModel> list = apiKeyTemplate.getApiKeyList(10001); // 该用户全部 Key
Object loginId = apiKeyTemplate.getLoginIdByApiKey("AK-xxx"); // Key 的授权人

// 修改（查出来改字段再保存）
model.setIsValid(false);        // 禁用
model.setExpiresTime(-1L);      // 改为永不过期
model.addScope("post.write");   // 追加 scope
apiKeyTemplate.saveApiKey(model);

// 删除
apiKeyTemplate.deleteApiKey("AK-xxx");            // 删单个
apiKeyTemplate.deleteApiKeyByLoginId(10001);      // 删该用户全部（一键回收）
```

`ApiKeyModel` 字段：

| 字段 | 说明 |
|------|------|
| `apiKey` | Key 值（自动生成或指定） |
| `loginId` | 绑定的用户 id（授权人，必填） |
| `title` / `intro` | 名称 / 描述（建议注明用途，便于审计） |
| `scopes` | 授权范围列表 |
| `createTime` / `expiresTime` | 创建 / 过期时间（13 位毫秒，-1=永久） |
| `isValid` | 生效 / 禁用 |
| `extraData` | 扩展数据（Map） |

## 三、接口鉴权

### 3.1 注解方式

```java
// 必须携带有效 Key
@ApiKeyCheck
@RequestMapping("/akRes1")
public SaResult akRes1() { ... }

// 必须具备 scope: userinfo
@ApiKeyCheck(scope = "userinfo")
@RequestMapping("/akRes2")
public SaResult akRes2() { ... }

// 必须同时具备 userinfo + chat（AND，默认）
@ApiKeyCheck(scope = {"userinfo", "chat"})
@RequestMapping("/akRes3")
public SaResult akRes3() { ... }

// 具备 userinfo / chat 其一即可（OR）
@ApiKeyCheck(scope = {"userinfo", "chat"}, mode = ApiKeyCheck.Mode.OR)
@RequestMapping("/akRes4")
public SaResult akRes4() { ... }
```

### 3.2 代码方式

```java
// 校验（无效 / 过期 / 禁用抛 ApiKeyException）
apiKeyTemplate.checkApiKey("AK-xxx");

// scope 校验（不具备抛 ApiKeyScopeException）
apiKeyTemplate.checkApiKeyScope("AK-xxx", "userinfo");
boolean has = apiKeyTemplate.hasApiKeyScope("AK-xxx", "userinfo");  // 不抛异常版

// 归属校验（非本人 Key 抛 12312）
apiKeyTemplate.checkApiKeyLoginId("AK-xxx", 10001);
```

### 3.3 控制器内读取当前 Key

```java
// 与拦截器一致的取值顺序：query 参数 -> 请求头
String apikey = request.getParameter("apikey");
if (apikey == null || apikey.isEmpty()) {
    apikey = request.getHeader("apikey");
}
ApiKeyModel current = apiKeyTemplate.checkApiKey(apikey);
```

> ⚠️ 不要写 `akRes1(String apikey)` 形参——只能从 query 绑定，header 方式会拿到 null。

## 四、调用方如何传递 Key

| 方式 | 示例 |
|------|------|
| query 参数 | `/akRes1?apikey=AK-xxx` |
| 请求头 | `apikey: AK-xxx`（全小写） |

```bash
# query
curl "http://localhost:8090/akRes1?apikey=AK-xxx"

# header
curl -H "apikey: AK-xxx" http://localhost:8090/akRes1
```

## 五、错误码

| code | HTTP | 含义 |
|------|------|------|
| 12301 | 401 | 无效 API Key（不存在 / 已被删除） |
| 12302 | 401 | API Key 已过期 |
| 12303 | 401 | API Key 已被禁用 |
| 12304 | 500 | 字段自检未通过（保存时缺必填字段，属服务端 bug） |
| 12305 | 500 | 未开启索引记录却调用索引相关 API（服务端配置问题） |
| 12311 | 401 | 不具备指定 Scope |
| 12312 | 401 | Key 不属于指定用户 |

响应体（宿主异常处理器决定，sample 参考实现统一转 401）：

```json
{ "code": 12311, "message": "该 API Key 不具备 Scope：userinfo", "apiKey": "AK-xxx" }
```

## 六、安全建议（对标 OpenAI 官方最佳实践）

- 每个 Key 只授予单一用途（`title` 注明），scope 按最小化原则
- 强制有效期 + 定期轮换：过期前创建新 Key、切换、再删旧 Key
- Key 泄露立即 `deleteApiKey`（秒级生效，全实例同步）
- `AK-` 前缀可被 secret 扫描工具识别，配合 Git 提交扫描防泄露
- Key 明文随请求传输，**敏感操作（资金 / 订单 / 回调）请叠加 apiSign 接口签名**

## 七、示例接口（api-key-sample，端口 8090）

| 接口 | 说明 |
|------|------|
| `GET /debug.html` | 可视化调试台（创建 / 编辑 / 一键调用） |
| `GET /createApiKey?loginId=` | 创建 Key |
| `GET /myApiKeyList?loginId=` | 查询用户 Key 列表 |
| `GET /updateApiKey` | 修改（apiKey + loginId + scopes[] + expiresTime + isValid） |
| `GET /deleteApiKey?apiKey=&loginId=` | 删除（校验归属） |
| `GET /deleteMyAllApiKey?loginId=` | 删除该用户全部 |
| `GET /akRes1?apikey=` | 校验 Key（无 scope 要求） |
| `GET /akRes2?apikey=` | 要求 scope: userinfo |
| `GET /akRes3?apikey=` | 要求 userinfo + chat（AND） |
| `GET /akRes4?apikey=` | 要求 userinfo / chat 其一（OR） |
